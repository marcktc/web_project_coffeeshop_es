# web_project_coffeeshop_es

Triple Espresso
Página de una tienda de café. Esta página está creada para ofrecer al cliente información clave sobre el extablecimiento (Horarios, Contactos, Dirección, etc.) y para que puedan realizar reservaciones.
Esta página está creada utilizando los lenguajes HTML y CSS, contiene flexbox, divisores, secciones, id's, interactividad, estados hover, entre otras cosas.
Me gustaría, además de añadir más interactividad, cambiar, por ejemplo, el formato en que se selecciona la fecha y hora de la reservación. Además, poder alojar las diferentes secciones en diferentes páginas.
